# Contributing

Thanks for your interest in contributing.

## Before you start

- **Open an issue first** for anything beyond typo fixes. Describe what you want to change and why.
- Wait for a response before starting work. This avoids wasted effort on changes that don't fit the project's direction.

## What this project is

A simple set of Node.js scripts that extract React source code from Figma Make files. The goal is to stay simple and lightweight.

## Pull requests

- Keep changes small and focused.
- Don't restructure the project, add frameworks, or introduce new tooling without prior discussion.
- Make sure existing scripts still work after your changes.
